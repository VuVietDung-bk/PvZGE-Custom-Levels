Zombies:

#COMMENT: To spawn a certain zombie in, place their codename before "@ZombieTypes" so for example: "RTID(iceage_armor2@ZombieTypes)", failing to do so will summon a basic browncoat.

For specific rows:
					{"Row": "1", "Type": "RTID(@ZombieTypes)"},
					
For in general:
					{"Type": "RTID(@ZombieTypes)"},
					
#COMMENT: For Rally Zombies to spawn over Flags Zombies please place this code in "WaveManagerProps" "objdata" area. 0 = Flag, 1 = Rally, you should have as many 0's or 1's for each flag interval
so if you have 3 "FlagWaveIntervals" you would have [0, 1, 1].
					
					"FlagWaveVeteranOverrideTypes": [0, 1], #COMMENT: This would be for a 2 Flag level.
